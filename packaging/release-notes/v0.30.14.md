# v0.30.14 — the token report knows Fable 5.2 and the 5.5 models

This release fixes the dollar figures in the token report, the script that reads your Claude Code transcripts and tells how much went into keeping the vault and how much into the code. Claude Fable 5.2, Opus 5.5, Sonnet 5.5 and Haiku 5.5 came out, and the report counted their runs as $0. On one real project the total at list prices more than doubled over the same transcripts, and the vault's share of the cost fell from about 40% to about 25%. If you made decisions from the report since the end of September, run it again.

The report is a script, not a verb of the CLI. Run it from a terminal in your project, from the installed copy. For the npm install that is:

```
node ~/.claude/projectstore/marketplace/projectstore/scripts/tokens.mjs
```

For the git marketplace, the copy is under `~/.claude/plugins/cache/SmartAndPoint/projectstore/<version>/scripts/tokens.mjs`, with the version written out.

## Prices

The price table now has the four new models at their list prices of 2026-11-10, in USD per million tokens:

- Fable 5.2: $8 input and $40 output
- Opus 5.5: $4 and $20
- Sonnet 5.5: $2 and $10
- Haiku 5.5: $0.10 and $0.50

Cache reads were always counted at 0.1× input. A model can now carry its own read rate. Fable 5.1 and 5.2 read at 0.025× input, and Opus 5.5 and Sonnet 5.5 at 0.05×. Fable 5.1 had been counted at 0.1× before, so its cache reads cost four times too much in the report. Cache writes stay at 1.25× and 2× input.

If a transcript record carries a short name (`fable`, `opus`, `sonnet`, `haiku`) instead of a full model id, it is priced as the newest model of that line on the Anthropic API. The records we have seen carry full ids.

What the report does not model: fast mode (twice the price on Fable 5.2 and Opus 5.5), US-only inference, Haiku 5.5's higher price for prompts over 100K tokens, and Amazon Bedrock, Google Cloud and Foundry prices. The `--json` output carries the price arrays as they are, with two or three values.

## The critic on Fable 5.2

Nothing to change in projectstore. An overlay that names `fable` for an agent, such as the critic, runs it on Fable 5.2 on a current Claude Code: it resolves the short name to the newest Fable, unless `ANTHROPIC_DEFAULT_FABLE_MODEL` pins another.

## Upgrading

Nothing migrates, no state moves, and the agents block stays v5. Codex's skills do not change.

From npm, from a terminal in your project:

```
npx projectstore@0.30.14 upgrade
```

From the git marketplace, in a Claude Code session: open `/plugin manage` and choose **Update now** on projectstore, then run `/reload-plugins` to load it. Or, from a terminal, then restart Claude Code:

```
claude plugin update projectstore@SmartAndPoint
```
