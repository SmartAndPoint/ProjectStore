# v0.30.13 — the plan gate asks its open questions once, before the plan

This release makes the plan gate collect the open questions of a story, put them to you in one round of at most five, and keep the answers in the story. An unclear point no longer surfaces only during the code, or gets settled by the agent without a word.

## One round of open questions

The planner now returns an "Open questions" item: at most five decisions that the code and the vault cannot answer, the one that changes the plan most first. Each has two to four options and one recommended option. "None" is the normal case. With more than five, it returns five, says how many it left out, and suggests splitting the story, which is probably too big. The planner asks you nothing.

`/projectstore:story plan` puts them to you before it writes the plan, in one round. Up to four questions go through the harness's question tool in one call. Five, or a harness with no question tool, get one plain-text message with the questions numbered. The round is asked once per gate run. A question you skip, or every question of a call you dismiss, takes its recommendation, marked `(assumed)`.

The answers go under a `### Clarifications` subsection, last in the plan, with the date; a later plan run adds its own dated line. An answer that changes a contract of the covering spec says which one, and the spec is amended before the code. No script reads the subsection: the plan gate keeps it, and doctor's findings do not change.

## Upgrading

Nothing migrates, no state moves, and the agents block stays v5. Existing plans are not changed. Codex's story and planner skills change, so Codex needs its own upgrade, below.

From npm, from a terminal in your project:

```
npx projectstore@0.30.13 upgrade
```

Codex's registration is per machine:

```
npx projectstore@0.30.13 upgrade --harness codex
```

From the git marketplace, in a Claude Code session: open `/plugin manage` and choose **Update now** on projectstore, then run `/reload-plugins` to load it. Or, from a terminal, then restart Claude Code:

```
claude plugin update projectstore@SmartAndPoint
```
