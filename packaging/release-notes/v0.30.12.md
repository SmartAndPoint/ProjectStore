# v0.30.12 — a story can say how it is checked on its own

This release adds one optional line to the story template. It is for the stories that have no spec, which is most of them: the line says how the story is checked on its own.

## The Independent test line

Under Description, every new story now has an optional line:

```markdown
**Independent test:** run `npm test` with a fixture vault whose index has a
stale row, and see doctor report the folder.
```

The label is translated in each of the six template languages, and a short comment says what the line is for. It is one sentence: a command to run and what to see.

`/projectstore:story` fills the line when the conversation already says how the story is checked. Otherwise it leaves the placeholder, and you fill it or delete it; it never invents one. At close, when the line is filled, the Final Summary's tests executed say whether that test ran and how, or why not.

The reviewer gives a filled line its own line in the acceptance matrix: the evidence, or `not run` with the reason. With neither, it is a should-fix, never a blocker. The line is a hint, not a gate: no script reads it, and doctor's findings are the same with it, without it, and with the placeholder.

[`docs/contracts-and-tests.md`](https://github.com/SmartAndPoint/ProjectStore/blob/main/docs/contracts-and-tests.md) shows the line.

## Upgrading

Nothing migrates, no state moves, and the agents block stays v5. Existing stories are not changed; only new ones get the line. Codex's story and reviewer skills change, so Codex needs its own upgrade, below.

From npm, from a terminal in your project:

```
npx projectstore@0.30.12 upgrade
```

Codex's registration is per machine:

```
npx projectstore@0.30.12 upgrade --harness codex
```

From the git marketplace, in a Claude Code session: open `/plugin manage` and choose **Update now** on projectstore, then run `/reload-plugins` to load it. Or, from a terminal, then restart Claude Code:

```
claude plugin update projectstore@SmartAndPoint
```
