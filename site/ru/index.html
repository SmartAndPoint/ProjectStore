ProjectStore

Агент сказал «готово». А точно?

С ProjectStore ему придётся это доказать. Сначала план, второй агент ищет в нём дыры, третий сверяет результат с вашим чек-листом — по каждому пункту. Плагин для Claude Code и Codex.

Хватит каждое утро заново объяснять агенту проект.

Решения, планы и прогресс сохраняются файлами в репозитории. Новая сессия — или другой агент — читает их и продолжает с того места, где вы остановились. Плагин для Claude Code и Codex.

Кончились лимиты в Claude? Продолжайте в Codex — с того же места.

Оба агента читают один и тот же план, те же решения и ту же доску задач в вашем репозитории. Меняйте инструмент и не теряйте нить. Плагин для Claude Code и Codex.

Вайбкодинг без легаси.

То, что вы быстро собрали сегодня, будет понятно и через месяц: у каждого решения записана причина, у каждой фичи — чек-лист, у каждого «готово» — проверка. Плагин для Claude Code и Codex.

Меньше переделок. Агент сначала думает, потом пишет.

Дыры находятся в плане, пока это ещё одна фраза, а не после двух часов кода. Вы одобряете план — потом агент строит. Плагин для Claude Code и Codex.

Дайте агенту задачу — получите ожидаемый результат. И продолжайте с любым агентом, где угодно.

План вы одобряете до кода, второй агент проверяет план, третий сверяет с ним код. Решения, планы и задачи лежат Markdown-файлами в вашем git, поэтому работу можно продолжить в другой сессии, на другой машине или другим агентом. Плагин для Claude Code и Codex.

Install the projectstore plugin from https://github.com/SmartAndPoint/ProjectStore and set it up for this project.

Для Claude Code. В Codex — вкладка «Терминал».

~/your-project $
npx projectstore setup

Работает в Claude Code и Codex. Скоро OpenCode, следом Gemini, Z.ai и DeepSeek.

Знакомо?

  • Агент сказал, что всё работает. Не работает.

    → Ревьюер не закроет задачу, пока не проверен каждый пункт чек-листа.

  • Утром новая сессия — и опять объяснять, что это за проект.

    → Сессия начинает с доски задач и текущей задачи.

  • Он снова предлагает Mongo, хотя вчера выбрали Postgres.

    → Решение записано вместе с причиной, и агент ему следует.

  • Кончились лимиты, а Codex ничего не знает о проекте.

    → Codex читает те же файлы и продолжает.

  • Через месяц сами не понимаете, почему код такой.

    → У каждого решения есть файл с причиной и отвергнутыми вариантами.

Быстрый старт

  1. Установите

    Через блок наверху: попросите агента или выполните команду в терминале в папке проекта. В Codex — только терминал. Нужен Node.js 20 или новее, macOS или Linux. После установки перезапустите агента; Codex один раз попросит одобрить его хуки.

  2. Скажите, что хотите сделать

    I want to create a stock trading bot

    «Хочу сделать бота для торговли акциями»

  3. Ответьте на вопросы

    Прежде чем планировать, агент спрашивает то, что решать только вам:

    The project is empty—no code, and the vault just has README scaffolding with no epics, stories, or ADRs yet. Per CLAUDE.md, I'll start with an epic and its stories in the vault rather than code, but first I need you to make a few decisions that will shape the plan.

    Перевод: «Проект пустой, кода и заметок пока нет. Начну с плана, а не с кода. Но сначала нужны ваши решения».

    Should the bot trade real money? (торговать реальными деньгами?)

    1. Paper only (Recommended) · учебный счёт
    2. Backtest only · исторические данные, без брокера
    3. Live, with safeguards · аварийная остановка, лимиты позиций и убытка

    Из настоящей сессии Claude Code в пустом проекте, 21 октября 2026. Текст агента дословный, описания вариантов сокращены, русский — перевод.

  4. Одобрите план

    К этому моменту критик его уже проверил. После вашего «да» агент делает работу, а ревьюер сверяет результат с чек-листом.
