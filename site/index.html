ProjectStore

Your agent said “done”. Is it?

With ProjectStore it has to prove it. The agent plans first, a second agent pokes holes in the plan, and a third checks the result against your checklist, point by point. A plugin for Claude Code and Codex.

What you can do

Just talk to your agent, in your own words. For example:

Start a project from an idea

I want to create a stock trading bot

It asks what only you can decide, then writes the plan: epics, stories, a checklist for each. No code yet.

Decide once

Let's go with Postgres, not Mongo — we need transactions.

The decision becomes a file with the options you turned down. Later sessions follow it instead of deciding again.

Build a feature by its checklist

Take the next story and build it

The planner finds where it goes, the agent writes code and tests, and the reviewer checks every point before it counts as done.

Pick up tomorrow

Where were we?

A new session reads the board and the story in progress, and carries on from there.

Quick start

  1. Install

    Use the box at the top: ask your agent, or run the command in a terminal in your project folder. In Codex, always the terminal. Needs Node.js 20 or later, on macOS or Linux. Restart the agent afterwards; Codex asks you once to approve its hooks.

  2. Say what you want to build

    I want to create a stock trading bot

  3. Answer its questions

    The agent asks what only you can decide, before it plans:

    The project is empty—no code, and the vault just has README scaffolding with no epics, stories, or ADRs yet. Per CLAUDE.md, I'll start with an epic and its stories in the vault rather than code, but first I need you to make a few decisions that will shape the plan.

    Should the bot trade real money?

    1. Paper only (Recommended) · paper/sandbox account
    2. Backtest only · historical data, no broker
    3. Live, with safeguards · kill switch, position limits, daily loss cap

    From a real Claude Code session on an empty project, 21 October 2026. The agent's text is quoted word for word; the option details are shortened.

  4. Approve the plan

    The critic has checked it by then. After your yes, the agent builds it, and the reviewer checks the result against the checklist.
